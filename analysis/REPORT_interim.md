# 1年分の要因分析（中間報告・血統以外）

- 対象：2025-11-01〜2026-10-25 のJRA平地 3,331レース／46,082頭（障害除外、前走情報は2025-08以降から作成）
- 基準：確定単勝オッズから推定した3着内確率（市場ベースライン）。要因の効果は「実際の3着内数 ÷ 市場の期待数（A/E）」
- 検証：前半(H1: 11〜4月)と後半(H2: 5〜10月)で同じ向きに出るか、多重検定補正(BH法)

## 1. 結論
- 市場（オッズ）が非常に強い。オッズだけのモデル AUC 0.809 に対し、オッズなし全要因モデルは 0.728
- 全要因を足した機械学習でも、後半期間の改善はごくわずか（logloss 0.4131→0.4128）
- 2要因の組み合わせ（約21,600セル）では、補正後に有意なものはゼロ
- 人気別3着内率：1番人気66.4%／2番53.3%／3番40.3%／4番34.3%／5番25.9%

## 2. 市場が過小・過大評価している要因（前後半とも同じ向き）
| 要因 | 頭数 | A/E | 意味 |
|---|---|---|---|
| 2走前 6〜8着 | 7,554 | 1.09 | 市場が過小評価（巻き返し） |
| 前走4角 中団（前から13〜53%） | 約15,800 | 1.04〜1.05 | 過小評価 |
| 芝⇔ダート替わり | 4,711 | 0.88 | 過大評価 |
| 斤量がレース平均より1kg以上軽い | 9,485 | 0.94 | 過大評価 |
| キャリア1戦以下 | 13,029 | 0.95 | 過大評価 |
| 昇級初戦 | 7,740 | 0.95 | 過大評価 |
| 休み明け78日以上 | 7,900 | 0.95 | 過大評価 |
| 前走4角 先頭付近 | 8,538 | 0.96 | 過大評価 |

前半だけで選んだ12要因のうち、後半でも有意に再現したのは6つ（同じ向きは9つ）。

## 3. 補正モデルの試算（前半で係数推定→後半で検証）
- 本命（各レース最上位）の3着内率：市場のみ 64.6% → 補正後 65.1%
- 本命が入れ替わった190レース：市場本命 51.6% → 補正後本命 55.8%
- 注意：補正要因の候補選びに後半データも使っているため、後半の数値はやや楽観的

## 4. 注意点
- 確定オッズを使用。予想時点のオッズとはずれがある
- 複勝回収率は全区分で100%未満（参考値）

## 5. 血統要因（追加分析・12,963頭）
- 種牡馬・母父の「市場比の過去成績」（全体／芝ダ×距離帯別／芝ダ×馬場別）を検証
- 多重検定補正後に有意なものはなし（最小 q=0.15）。前後半で再現したものもなし。効き方も単調でない
- 全要因モデルに血統を足しても、後半期間の改善はごくわずか（logloss 0.41279→0.41270）
- 結論：血統は補正要因に加えない（オッズにほぼ織り込み済みと考えられる）
- 注意：血統の過去成績は2025/8以降の分しか集計していないため、データが少ない種牡馬は評価が弱い
